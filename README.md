# Mi Aula EINA

Sube tu horario `.ics` de la Universidad de Zaragoza y la maqueta 3D del Campus Río Ebro (EINA) te marca el aula de cada clase, con la entrada, escalera y ascensor más cercanos.

- Descarga tu horario en la [Consulta pública de horarios de Unizar](https://sia.unizar.es/pds/consultaPublica/look[conpub]InicioPubHora?entradaPublica=true) (botón «Descargar archivo ICS»).
- El archivo se lee en tu navegador: no se envía a ningún servidor.

Planos y datos de espacios: visor IDEUZ (Campus FiDigital, Universidad de Zaragoza). Proyecto no oficial; comprueba siempre el horario oficial.
